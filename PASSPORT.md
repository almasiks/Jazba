# Jazba — паспорт проекта (MVP)

> Конкурс Codex Challenge, проект ChatGPT Edu.

## Паспорт проекта

**Название проекта и автор:** Jazba — ИИ-помощник ментора: из записи занятия в готовые учебные материалы. Автор: Магрупов Алмас (Алматы), студент TechOrda, DSA Science Academy.

**Направление:** школы Tech Orda (Astana Hub).

**Проблема и пользователь:** пользователь — ментор (преподаватель) IT-курса Tech Orda. После каждого занятия ему нужно подготовить конспект, тест, домашнее задание и ответить на вопросы студентов. На это уходят часы, поэтому чаще всего материалы не готовятся вовсе, а запись занятия на 1,5–2 часа лежит без пользы. Студенты, пропустившие занятие, вынуждены пересматривать её целиком.

**Основной сценарий:** ментор загружает транскрипт занятия из Zoom (.vtt) и отмечает себя среди спикеров → продукт обезличивает имена студентов и с помощью ИИ генерирует пакет материалов → ментор получает конспект с таймкодами, тест с объяснениями, домашнее задание с критериями, FAQ и глоссарий (қаз / рус / eng), правит их и публикует ссылкой для студентов.

**Форма продукта:** веб-приложение (сайт) с ИИ-генерацией: кабинет ментора и мобильная страница для студентов.

**AI-инструменты и вклад:**
- Codex — написание кода приложения по заданиям автора.
- Claude — помощь с идеей, планом этапов, заданиями для Codex и дизайн-макетами экранов.
- Google Gemini (Google AI Studio, бесплатный тариф) — генерация материалов внутри продукта.
- Автор: выбор проблемы и пользователя, постановка задач и проверка результата каждого этапа, промпты генерации и их доработка на тестовых транскриптах, решения по приватности (обезличивание имён), выбор дизайна, тестирование.
- Готовые материалы: Next.js, React, Tailwind CSS, shadcn/ui, lucide-react, zod, OpenAI SDK, Supabase JS (открытые лицензии MIT / Apache-2.0 / ISC). Проект новый, создан в рамках конкурса.

**Условия запуска в workspace:** для проверки нужен только браузер: без регистрации, без пароля, без оплаты и личных аккаунтов (открытый демо-стенд, `PUBLIC_DEMO=true`). Сервисы автора: хостинг Vercel и база Supabase (бесплатные тарифы), ИИ-API Google Gemini (бесплатный тариф). Ключи хранятся только в переменных окружения сервера и не входят в репозиторий и материалы проверки. Расходы для проверяющего: нет.

**Данные и ограничения:**
- Для проверки используется синтетический транскрипт занятия `samples/js-arrays-lesson.vtt` (14:40, тема map/filter/reduce). Реальных данных студентов нет.
- Имена студентов заменяются на «Студент 1, 2…» в браузере до отправки текста в ИИ; в ИИ уходит только обезличенный текст.
- Работает: загрузка .vtt и текста, генерация 5 блоков, таймкоды, редактирование и перегенерация блоков, публикация, страница студента с тестом, PDF, удаление занятий, метрика времени подготовки.
- Не реализовано: загрузка видео с автоматической транскрибацией (нужен готовый транскрипт), интеграция с LMS.
- Имитация: если ключа ИИ нет или включён `MOCK_GENERATION=true`, показываются заранее подготовленные материалы с плашкой «Демо-режим: без ИИ».
- Ограничения: бесплатный тариф ИИ-API имеет дневной лимит запросов; генерация дополнительно ограничена лимитами приложения. На открытом стенде занятия видны всем проверяющим. ИИ может ошибаться, поэтому материалы публикуются только после проверки ментором.

## Запуск и проверка

**Workspace ChatGPT Edu организации:** workspace ChatGPT Edu организаторов конкурса (по их инструкции).

**Название опубликованного объекта:** Jazba — Магрупов Алмас

**Адрес стенда для проверки:** https://jazba-review.vercel.app/ (без входа и без оплаты)

**Сдаваемая версия и дата публикации:** MVP v0.1, 17 ноября 2026

**Инструкция:**
1. Откройте https://jazba-review.vercel.app/ (или объект «Jazba — Магрупов Алмас» в workspace). Входить не нужно: сверху плашка «Открытый демо-стенд».
2. На странице «Новое занятие» выберите вкладку «Файл .vtt из Zoom».
3. Нажмите «Загрузить пример .vtt».
4. В списке спикеров выберите «Ерлан Сапаров» — появится отметка «Это я».
5. В превью того, что уйдёт в ИИ, убедитесь, что вместо имён студентов стоят «Студент 1–3».
6. Нажмите «Сгенерировать материалы» и дождитесь редактора (1–2 минуты).
7. Просмотрите блоки слева: Конспект, Тест, Домашка, FAQ, Глоссарий.
8. Нажмите «Опубликовать», затем в блоке «Ссылка для студентов» — «Открыть».
9. На странице студента пройдите тест: после ответа видно объяснение, при ошибке — «Пересмотри с мм:сс».

**Исходные тестовые данные:** синтетический транскрипт `js-arrays-lesson.vtt` (14:40; ментор Ерлан Сапаров и студенты Мария Ким, Айгерим Нурланова, Данияр Ахметов; русская речь с казахскими фразами и английскими IT-терминами). Встроен в приложение кнопкой «Загрузить пример .vtt».

**Действия и кнопки:** «Файл .vtt из Zoom» → «Загрузить пример .vtt» → выбор спикера → «Сгенерировать материалы» → «Опубликовать» → «Открыть».

**Ожидаемый результат и признаки правильной работы:**
- Нет плашки «Демо-режим: без ИИ» — материалы созданы ИИ по этому транскрипту.
- В материалах нет имён Мария, Айгерим, Данияр — только «Студент 1–3».
- Конспект разбит на разделы по map / filter / reduce с таймкодами в пределах 00:00–14:40.
- Тест: 5–10 вопросов по теме, у каждого объяснение; после неверного ответа — «Пересмотри с мм:сс».
- Домашка по теме занятия с критериями проверки; FAQ содержит вопросы студентов из записи.
- Страница студента открывается по ссылке, тест проверяет ответы, в конце показан итог.
