# Jazba

> «Жазба» — запись, заметка (каз.). Jazba — из записи занятия в готовые материалы: ИИ-помощник ментора Tech Orda.

Проект для конкурса **Codex Challenge** (Bilim AI × OpenAI, ChatGPT Edu), ноябрь–декабрь 2026.

---

## Проблема

После каждого занятия ментор Tech Orda должен подготовить материалы: конспект, тест, домашнее задание, ответы на вопросы. На это уходят часы, поэтому чаще всего этого не делают вовсе. Запись занятия на 1,5–2 часа лежит без пользы, а студенты, которые пропустили занятие или не поняли тему, вынуждены пересматривать всё целиком.

## Решение

Ментор загружает транскрипт (или запись) занятия и за пару минут получает пакет материалов:

1. **Конспект** — по разделам, с таймкодами на нужную минуту записи.
2. **Мини-тест** — 5–10 вопросов, у каждого ссылка «пересмотри с мм:сс».
3. **Домашнее задание** — по теме занятия, с критериями проверки.
4. **FAQ** — вопросы, которые задавали студенты, и ответы ментора.
5. **Глоссарий** — термины занятия на казахском, русском и английском.

**Ментор всегда редактирует и одобряет материалы перед публикацией.** ИИ делает черновик, не финальную версию.

## Пользователи

- **Ментор** — загружает, проверяет, редактирует, публикует.
- **Студент** — открывает материалы по ссылке, проходит тест.

## Особенности

- Речь на занятиях смешанная: русский, казахский, английские IT-термины. Генерация должна это корректно обрабатывать.
- Таймкоды связывают все материалы с записью.
- Ценность измеряем временем: «было 2–3 часа на материалы, стало ~15 минут».

|---|------|-----------|

| 5 | Тест и защита | Пилот с 2–3 менторами, замер «после», отзывы, презентация |

## Стек

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS** + **shadcn/ui**
- **OpenAI API** — генерация материалов (Structured Outputs / JSON schema), позже — транскрибация
- Модель задаётся в `.env.local` через `OPENAI_MODEL`, ключ — `OPENAI_API_KEY`
- Хранение: `lib/storage.ts` (интерфейс LessonStorage): `STORAGE=local` — JSON-файлы в `data/lessons/` (разработка), `STORAGE=supabase` — Supabase (деплой)
- Деплой: Vercel; вход ментора по `MENTOR_PASSWORD`, страница студента открыта

## Структура (план)

```
app/
  page.tsx                 — главная: ввод транскрипта, кнопка «Сгенерировать»
  result/                  — просмотр материалов (этап 2–3)
  api/generate/route.ts    — генерация материалов
lib/
  openai.ts                — клиент OpenAI
  prompts.ts               — все промпты в одном месте
  schema.ts                — типы и JSON-схема материалов (zod)
  vtt.ts                   — парсер .vtt (этап 3)
components/                — UI-компоненты блоков материалов
samples/                   — тестовые транскрипты занятий
```

## Формат материалов (JSON)

```ts
type Materials = {
  title: string;               // тема занятия
  summary: {                   // конспект
    heading: string;
    timestamp?: string;        // "мм:сс" или "чч:мм:сс" — где начинается раздел
    points: string[];
  }[];
  quiz: {
    question: string;
    options: string[];         // 4 варианта
    correctIndex: number;
    explanation: string;
    timestamp?: string;        // где это объяснялось
  }[];
  homework: {
    task: string;
    requirements: string[];
    criteria: string[];        // критерии проверки
  };
  faq: { question: string; answer: string; timestamp?: string }[];  // timestamp — где прозвучал вопрос
  glossary: { term: string; kk: string; ru: string; en: string; definition: string }[];
};
```

## Принципы промптов

- Опираться **только** на содержание транскрипта, ничего не выдумывать. Если в занятии чего-то не было — не добавлять.
- Язык материалов — язык, выбранный ментором (по умолчанию русский); IT-термины оставлять как есть.
- Тест проверяет понимание, а не запоминание формулировок.
- Домашка — практическая, по теме занятия, выполнимая за 1–2 часа.
- FAQ — только из реальных вопросов студентов в транскрипте; если их нет — пустой список.
- Транскрипт может быть «грязным» (оговорки, паузы, смешение языков) — это нормально.

## Правила для кода

- Комментарии и тексты интерфейса — на русском.
- Ключи только в `.env.local`, никогда не в коде и не в git.
- Не отправлять в API лишние персональные данные студентов.
- Маленькие понятные компоненты; промпты — только в `lib/prompts.ts`.
- После каждого изменения проект должен запускаться (`npm run dev`).
